## 二、本次变更（v1.2）

### 1. 🔴 三路遥控共存 + 输入源仲裁（核心）

v1.1 做不到"三共存"，不只是 SBUS 默认关闭的问题 —— 更关键的是两路会**打架**：
`readRC()`（SBUS）与 `processMavlink()` 的 `MANUAL_CONTROL`（ESP-NOW）写同一组
`controlRoll/Pitch/Yaw/Throttle`，没有任何仲裁，而主循环里 `processMavlink()` 排在后面，
于是 ESP-NOW 每轮后写，杆量在两个源之间交替覆盖。

v1.2 引入 `RC_SRC` 参数：

| RC_SRC | 行为 |
| --- | --- |
| `0`（出厂默认） | 自动：SBUS 最近 0.3 s 内有有效帧 → SBUS 说了算；否则 ESP-NOW |
| `1` | 强制 ESP-NOW：`readRC()` 直接返回，连 SBUS 都不读（排查隔离用） |
| `2` | 强制 SBUS：无帧也不回落（确认是否 SBUS 的问题；代价是没接线飞不了） |

`rc` 命令新增一行「当前输入源：SBUS / ESP-NOW / 无」，启动日志会打印
「遥控：已启用 SBUS，接收脚 GPIO1（不接接收机也不影响 ESP-NOW）」。

### 2. 🔴 安全修复：未标定的 SBUS 会满油

这是一条必须先修的坑，否则"默认打开 SBUS"就是安全隐患：

- `channelZero[] / channelMax[]` 全局零初始化，全新板两者都是 0；
- `normalizeRC()` 的 `mapf(x, 0, 0, 0, 1)` **除零得到 ±inf**；
- `control.ino` 是 `thrustTarget = controlThrottle;`，**没有 clamp** ⇒ 一推杆就满油或 NaN。

两道保险：

- **除零保护**：通道行程 < 100（量程 1639 的 6%）一律输出 0，并只提示一次
  `⚠ 通道 n 未标定（零位=… 满量程=…），该通道已按 0 处理`；
- **出厂预置标定**（仅 S3 板）：按 S.BUS 规范 172 / 992 / 1811 预置通道映射（AETR + 模式第 5 通道）
  与零位/满量程。写在 `setDefaults()` 里，而参数加载顺序是"先默认值、再读 NVS"，
  所以跑过 `cr` 的板子保留实测值，不会被覆盖。

### 3. 其它

- 版本号、开机横幅（`遥控：ESP-NOW + SBUS`）、`rc` 命令帮助同步更新；
- 中文固件行为与 v1.1 的差异仅限遥控通路（三路仲裁 + 上面的安全修复），其余未动；
- i18n 中英宏配对 176:176（v1.1 是 170:170，新增 6 条），`tools/check_i18n.py` 全绿。

## 三、烧录

**S3（耀坤板）**

- 首次 / 想彻底重置：写 `整片8MB.bin` 到 `0x0`（会清 NVS：热点名、IMU 标定、遥控标定全丢）；
- 只想升级、保留标定：写 `merged.bin` **分片**（`0x0` bootloader / `0x8000` partitions / `0xe000` boot_app0 / `0x10000` app）。
  ⚠️ 把 `merged.bin` 从 0x0 一连续写会覆盖 `0x9000` 的 nvs 分区 —— 这是最常见的"标定白做"原因。

**火龙果 2.0**

- 🔴 经典 ESP32 的 bootloader 在 **0x1000**（S3 才是 0x0）。`整片4MB.bin` 已按正确偏移组装，从 `0x0` 整片写即可；
- 之后只更新 app 时写 `0x10000`，NVS 全保留。

## 四、已知限制（必须告诉用户）

1. **SBUS 首次使用仍建议跑一次 `cr`**。预置值只保证量程，不保证方向 ——
   各家遥控器通道正反向不同（AT9S Pro 实测满杆到过 1982，超出 S.BUS 规范值）。
   方向反了就把对应 `p RC_MAX_x` 与 `p RC_ZERO_x` 对调，未标定提示里已把这两个数打出来。
2. **用 SBUS 时建议把 ESP-NOW 遥控关机**。虽然 `RC_SRC=0` 会优先 SBUS，但同时开机没有任何好处。
3. **严禁在 QGC 里开虚拟摇杆**：`MANUAL_CONTROL` 不校验来源，会抢仲裁源。
4. 老版本（v1.1）的 NVS 里若存着 `RC_RX_PIN=-1`，升级后仍会是 -1（NVS 优先于编译默认值）。
   这种情况需要 `p RC_RX_PIN 1` 一次，或整片烧 `整片8MB.bin` 清 NVS。
