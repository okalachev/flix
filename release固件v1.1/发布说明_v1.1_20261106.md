## 二、本次变更（v1.1，2026-11-06 修订）

### 1. 🔴 修复打包脚本的致命缺陷（影响此前所有对外发布件）

ESP 应用镜像尾部有**两道**完整性数据：

- **XOR 校验字节** —— 各段数据逐字节 XOR，初值 `0xEF`，写在「下一个 ≡15 (mod 16)」
  的偏移处（即 16 字节块的最后一个字节）；
- **appended SHA-256** —— 末 32 字节。

脱敏脚本过去只重算了 SHA、**没重算 XOR 校验字节**。只要替换过 1 个字节日志路径，
校验和就废了，bootloader 报 `Checksum failed` 拒启。
现在 `pack_flix_release.py` 的 `fix_app_image_trailer()` 两处一起重算，
三份镜像均已修复并用**实机烧录**验证。

### 2. 新增微辣火龙果 2.0 板型支持

同一套源码，编译期用 `-DFLIX_BOARD=2` 切到火龙果：

- `Firmware/flix/board.h` 用一组 `PIN_*` 宏描述板型，**不做运行时认板**
  （电机脚没有身份标识，猜错上电即乱序起转）；
- 21 脚映射：电机 `26/27/33/32`（RL/RR/FR/FL）、IMU I2C `21/22` 或 SPI `18/19/23`+CS`5`、
  蜂鸣器 `25`、LED `2`、ADC `35`、SBus `4`、光流预留 `13/14/12/15`、激光 I2C1 `16/17`；
- 电机 PWM 与 S3 统一为 **38 kHz**（避开可听频段）。

### 3. 品牌归属与横幅

- 耀坤智联是**替火龙果作者做固件适配与维护**，不是火龙果本人，两块板品牌完全独立；
- 火龙果横幅按作者给定文案逐行呈现，末尾追加耀坤淘宝行；
- **耀坤 S3 横幅不含任何火龙果链接**（已复核并加编译期约束注释）。

### 4. 其他

- 技术说明书新增「十七、微辣火龙果 2.0 板型适配」（中英双语）；
- 新增 `Firmware/tools/gen_hlg_note.py`：火龙果说明由脚本现场生成，
  哈希/大小/编译时间不手写，避免文档漂移。

## 三、烧录速查（两块板规则不同，别混用）

| | 耀坤 S3 | 微辣火龙果 2.0 |
| --- | --- | --- |
| 芯片 | ESP32-S3 | **ESP32 经典** |
| 整片大小 | 8 MB | 4 MB |
| 整片烧录地址 | `0x0` | `0x0` |
| **bootloader 单独烧录** | **`0x0`** | **`0x1000`** |
| 分区表 / OTA / app | `0x8000` / `0xE000` / `0x10000` | 同左 |
| 串口驱动 | 原生 USB（HWCDC） | CH340 等 USB 转串口 |
| 串口参数 | 115200 8N1（打开时 DTR=1、RTS=0） | 115200 8N1（默认电平） |

🔴 **最常见的坑**：把 S3 的 `0x0` 照抄去烧火龙果 bootloader，
ESP32 经典片会在 `0x1000` 找不到 `0xE9`，症状是「烧录 verified 成功但板子不启动、
串口 0 字节、停在 waiting for download」。

整片固件最省事：`erase-flash` 后从 `0x0` 一次写完，不用管分段。
