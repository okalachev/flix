## 0. 准备工作

| 项 | 内容 |
| --- | --- |
| 固件 | `release固件v1.1/MildlySpicyDragon_火龙果2.0_Flix整理版_v1.1_20261106_整片4MB.bin`（SHA-256 与指纹见同目录《指纹与烧录说明》） |
| 串口 | USB-UART 虚拟 COM 口，115200。**别在串口助手里手动拉 DTR/RTS**——某些 USB-UART 芯片 `DTR=1,RTS=0` 恰好是「按住复位」，板子会一动不动 |
| 遥控 | 二选一：中文版 ESP-NOW 遥控，或 SBUS 接收机（接 GPIO4） |
| 其他 | **另一台飞机断电**（同频互相干扰，否则无法归因）；**拆桨** |

### 烧录速查（两种方式）

**方式 A：Flash Download Tool（图形界面，推荐）** —— 芯片选 **ESP32**（⚠️ 不是 ESP32-S3），Develop 模式，只添加整片 bin，地址填 **`0x0`**。

**方式 B：esptool**

```bash
# 整片烧（会清掉 NVS 里的标定 / 参数，新板或想重置时用）
esptool --port COMx --baud 460800 --before default-reset --after hard-reset \
  write-flash 0x0 MildlySpicyDragon_火龙果2.0_Flix整理版_v1.1_20261106_整片4MB.bin

# 只更新 app 区（0x10000），NVS 里的标定 / 热点名 / 信道全保留（日常升级用这个）
esptool --port COMx --baud 460800 --before default-reset --after hard-reset \
  write-flash 0x10000 flix.ino.bin
```

> 🔴 单独烧 bootloader 时地址是 `0x1000`，不是 S3 的 `0x0`（照抄会烧成「verified 但不启动」）。
> 烧完常停在下载模式：`esptool --after watchdog-reset run`，或拔插 USB。

## 2. IMU 自动识别（`imu`）

固件按总线自动识别，**先探 I2C（排母）、再探 SPI**。2026-11-06 实拍（排母空、SPI 模块在位）：

```
正在自动识别惯性测量单元…
识别为 MPU6050 系（I2C）SDA=21 SCL=22
  芯片标识（WHO_AM_I）= 0xFF
  安装朝向补偿：绕 Z 轴 +1.5708 弧度  [I2C id]
Incorrect device ID: 0x00
首次识别失败（型号 3 / 总数 1 / 状态 1），换型号重试
识别为 MPU6500 系（SPI）SCK=18 MISO=19 MOSI=23 CS=5
  安装朝向补偿：绕 Z 轴 -1.5708 弧度  [fallback]
IMU: MPU-6500 detected
惯性测量单元就绪：MPU-6500，总线 SPI
```

**判读**：

| 你插的模块 | 期望识别 | 总线 / 引脚 |
| --- | --- | --- |
| MPU6050（排母） | `MPU6050 … I2C0`，WHO=0x68 | SDA=21 SCL=22 |
| MPU6500（排母） | `MPU-6500 … SPI`，WHO=0x70 | SCK=18 MISO=19 MOSI=23 CS=5 |

- [ ] `imu` 显示的型号 / WHO_AM_I / 总线与实物一致
- [ ] **右侧压低 → `st` 横滚为正**（朝向唯一判据；I2C 补偿 +1.5708、SPI 补偿 −1.5708，固件自动选，不用手改）
- [ ] 静止平放时横滚 / 俯仰在 ±2° 内
- [ ] 芯片温度是真实值（≈40°C，为 0.0 说明没通）
- [ ] 换过 IMU 模块后**必须重跑 `ca`**（不同模块零偏不同）

- [ ] `pw` 显示的电压与万用表实测一致（±0.05V 内；分压系数 2 已按 GPIO35 的 100K+100K / 10K+10K 配好）

## 5. ESP-NOW 遥控（中文版遥控器）

与 S3 完全同流程，要点：

1. **开机**遥控器 → 进「对端发现」页 → **点选**那台飞机建立连接
2. **按「左按钮（辅助按钮）」使能控制输出** —— ⚠️ 界面上没有这个开关，是纯物理按键；按一次开、再按一次关
3. ⚠️ **飞机重启后必须重新连接 + 重新使能**（ESP-NOW 会话已清）

```
> wifi
```

| 现象 | 结论 |
| --- | --- |
| 接收包数 = 0 | 物理层没通 → 查信道（必须同为 1）、遥控器是否使能 |
| 包数 > 0，帧数 = 0 | 收到字节组不成 MAVLink 帧 → 遥控器在 Raw 协议模式 |
| 帧数 > 0，msgid ≠ 69 | 遥控器只发 HEARTBEAT（未使能 / 不在控制页） |
| msgid = 69，rc 全 0 | 未按左按钮使能 |

- [ ] 接收包数 / 解析帧数持续增长
- [ ] `最近一帧消息 ID：69（MANUAL_CONTROL）`、`来源 sysid：127`
- [ ] 油门量程：最低 ≈ **−1.0** / 中位 ≈ **0.0** / 最高 ≈ **+1.0**（❌ 若只有 `0 / +0.5 / +1.0` 正半程，**不要起飞**）

## 6. SBUS 遥控（火龙果特有，出厂默认启用 GPIO4）

> 火龙果的 SBUS 出厂就是开的（`PIN_RC_RX=4`），不像 S3 要先 `p RC_RX_PIN 1`。
> SBUS 与 ESP-NOW 两路互不叠加：SBUS 接了接收机就用 SBUS 的值，ESP-NOW 遥控的 MANUAL_CONTROL 各走各的分支。

- [ ] 接收机接 **GPIO4**（信号）、3.3V/5V、GND
- [ ] `rc` 能看到通道数值随打杆变化（SBUS 未接时 `rc` 会提示 SBUS 引脚号且数据不动，属正常）
- [ ] **`cr` 校准遥控行程**（8 步中文提示，每步 3 秒）：油门 / 偏航 / 俯仰 / 横滚 / 模式开关依次按提示打满——**模式开关（`cr` 第 8 步）必须放在两个极端档各停一次**，只放中间档会识别不到
- [ ] 校准结束打印「成功 N / 5」，N = 5 才算过
- [ ] `rc` 输出里模式开关数值随档位变化（三档 → 三档各不相同）
- [ ] 油门量程：最低 ≈ −1.0 侧、最高 ≈ +1.0 侧（`cr` 后 `rc` 实测）
- [ ] 解锁 / 上锁随遥控器开关正常

> 🔴 **不同遥控器的标定不能混用**（满杆值不同）——换遥控器必重跑 `cr`。
> 🔴 **别用 `preset` 全清参数**（会连 IMU 标定一起清）；只重置遥控就直接重跑 `cr`。

## 7. 电机与解锁（★必须拆桨）

```
> mfr 0.1   → 右前（GPIO33）    > mfl 0.1  → 左前（GPIO32）
> mrr 0.1   → 右后（GPIO27）    > mrl 0.1  → 左后（GPIO26）
```

- [ ] 四个电机都能转，**位置对应正确**（`mfr` 转的是右前那个；对照上表 GPIO 号）
- [ ] 转向符合四轴 X 型布局
- [ ] `mot` 未推油门时四路全 0

> 🔴 **「看电池电压压降判断电机转不转」是假判据**——台架插 USB 时电机吃的是 USB 5V→LDO，
> 电池端不掉压。真判据：耳朵听 / 看电机 / `mot` 输出值；要看电先拔 USB 只留电池。

解锁：
- [ ] 油门拉到最低 → `arm` 或遥控器解锁 → `rc` 中解锁状态 = 1
- [ ] 蜂鸣器三短鸣（GPIO25 有源蜂鸣器）
- [ ] 油门不在低位时尝试 `arm` → 打印「拒绝解锁：油门不在最低位」

## 8. 失联保护

固件逻辑（`safety.ino`）：解锁状态下 **1 秒收不到任何控制输入** → 进入缓降（AUTO 模式，油门线性下降）；**10 秒后油门归零并自动上锁**。

- [ ] 拔掉遥控器电源（或关接收机）
- [ ] 约 1 秒后飞机进入缓降逻辑（蜂鸣器提示，单灯转入对应闪频——火龙果是单灯，状态靠闪频区分，具体灯语以实测为准并回填到本表）
- [ ] 约 10 秒后油门归零并自动上锁

> ⚠️ SBUS 在用时拔 SBUS 线、ESP-NOW 在用时关遥控器，两种链路都要各测一次（controlTime 由实际在用的那路刷新）。

## 10. 实测中踩到的「假 bug」（别重复排查）

| 现象 | 真相 |
| --- | --- |
| `采样频率` 显示 20 Hz / 1 Hz | 它是 **`loopRate`（主循环频率）**，不是 IMU ODR。校准期、空闲期都正常，**不要改 `configureIMU()`** |
| 启动日志先报 I2C 识别失败再报 SPI 成功 | **正常回退流程**：I2C 排母为空 → WHO 读到 0xFF → 换 SPI 探测命中。不是故障 |
| `mot` 读数左右不对称、有 0 和 1 | 是 `desaturate()` **削顶**，四路失去可比性。验混控方向用 `Firmware/tools/mixer_sign_check.py` 离线算 |
| 执行 `ca` 后姿态彻底失真 | `ca` 是 48 秒连跑、无输入等待，人手跟不上六面翻滚 ⇒ 比例系数塌掉。救急：`p IMU_ACC_SCALE_X/Y/Z 1` + `p IMU_ACC_BIAS_X/Y/Z 0`，复位后 `st` 应回 ±2° 内 |
| 台架上「电机转了但电池电压没掉」 | 插 USB 时电机吃 USB 5V，电池端本来就不掉压（见第 7 节） |
| 串口打不开 / 板子没输出 | 先确认没在串口助手里手动拉 DTR/RTS（可能把芯片按进复位）；再查 USB-UART 驱动 |

## 11. 出问题怎么查

| 现象 | 先看什么 |
| --- | --- |
| 烧录 verified 但不启动 | 芯片是不是选错成 ESP32-S3 / bootloader 是不是烧到 0x0（应在 0x1000）；整片 bin 从 0x0 烧就不会错 |
| 横幅显示耀坤 S3 的内容 | 烧错固件了——这是火龙果整片 bin，重烧 |
| 遥控毫无反应（ESP-NOW） | `wifi` 的 `接收包数`；为 0 → 查信道（必须 1）、遥控器是否使能 |
| 遥控器显示已连接但飞机不动 | **按左按钮使能**（`enabled` 默认 false） |
| SBUS 打杆无反应 | `rc` 看通道；没校准 → 重跑 `cr`；接线查 GPIO4 |
| 模式开关切不了飞行模式 | `cr` 第 8 步没把开关打到两个极端档 → 重跑 `cr` |
| 电机不转 | 第 7 节假判据排除后，查 `mfr 0.1` 单测；都不转查解锁状态 |
| IMU 识别不出 | 对照第 2 节判读表查引脚（I2C=21/22，SPI=18/19/23/CS5）；接头插到底 |
| 电压恒 0 | 接线是否落在 GPIO35；见第 3 节 ADC1 说明 |
| 界面出现英文 | 烧了英文版或上游原版，看开机第一行 |
